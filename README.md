# Dual-Controller-Ambilight-with-Automatic-LED-Data-Switching
A dual-controller Ambilight setup using an Adafruit Feather RP2040 SCORPIO, HyperSerialPico, and an ESP32/WLED controller to drive the same SK6812 RGBW LED strip without physically reconnecting the LEDs.  The system automatically switches the LED data source depending on whether the TV is powered on.
